# 🕐 Shutdown Timer

Aplikasi sederhana untuk mengatur waktu shutdown komputer otomatis.

## 📋 Deskripsi

Shutdown Timer adalah aplikasi Windows yang memungkinkan Anda untuk menjadwalkan shutdown komputer secara otomatis. Cocok untuk situasi seperti:
- Download file besar di malam hari
- Render video yang memakan waktu lama
- Nonton film sebelum tidur
- Menghemat listrik dengan auto shutdown

## ⚡ Fitur

- ✅ **Mudah Digunakan** - Interface sederhana dan intuitif
- ✅ **Atur Waktu** - Set jam dan menit untuk shutdown
- ✅ **Batal Shutdown** - Batalkan shutdown yang sudah dijadwalkan
- ✅ **Lightweight** - Tidak memakan banyak resource komputer
- ✅ **Gratis** - 100% gratis tanpa iklan

## 💾 Cara Install

### Download:
📥 **[Download Shutdown Timer v1.0](https://github.com/xyukii/windows-shutdown-timer/blob/main/dist/ShutdownTimer_v1.0_Setup.zip)**

### Instalasi:
1. Download file `ShutdownTimer_Setup.exe` dari link di atas
2. Extract file ZIP yang telah didownload
3. Double-click file installer
3. Pilih lokasi instalasi (atau gunakan default: `C:\Program Files\Shutdown Timer`)
4. Ikuti wizard instalasi
5. Pilih apakah ingin shortcut di Desktop
6. Klik Install
7. Selesai! Program siap digunakan

### Uninstall:
1. Buka **Control Panel** → **Programs and Features**
2. Cari **Shutdown Timer**
3. Klik **Uninstall**
4. Atau gunakan uninstaller di Start Menu

## 🎮 Cara Menggunakan

1. **Jalankan aplikasi** dari Start Menu atau Desktop
2. **Pilih menu [1]** untuk mengatur timer shutdown
3. **Masukkan jam** (0-23) - contoh: 23 untuk jam 11 malam
4. **Masukkan menit** (0-59) - contoh: 30 untuk 30 menit
5. **Konfirmasi** - Komputer akan shutdown otomatis pada waktu yang ditentukan
6. **Untuk membatalkan**, jalankan kembali aplikasi dan pilih menu [2]

### Contoh Penggunaan:
- Ingin shutdown jam 11:30 malam → Masukkan jam: **23**, menit: **30**
- Ingin shutdown jam 2:00 siang → Masukkan jam: **14**, menit: **0**
- Ingin shutdown jam 12:15 malam → Masukkan jam: **0**, menit: **15**

## 🔧 Troubleshooting

**Q: Aplikasi tidak muncul setelah diklik?**
A: Pastikan VBScript tidak diblokir oleh antivirus. Tambahkan ke whitelist.

**Q: Timer tidak berfungsi?**
A: Pastikan Anda menjalankan aplikasi sebagai Administrator.

**Q: Bagaimana cara membatalkan shutdown?**
A: Buka aplikasi lagi dan pilih menu [2] Batal Matikan Komputer.

**Q: Komputer tidak shutdown tepat waktu?**
A: Periksa apakah ada aplikasi yang mencegah shutdown. Tutup semua aplikasi terlebih dahulu.
